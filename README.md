# Scores4AI repository

The runnable Scores4AI app lives in `scores4ai (1)`.

Start with the app README:

- `scores4ai (1)/README.md`
- `scores4ai (1)/SUPABASE_SETUP.md`
- `scores4ai (1)/AUTOMATION_WORKFLOWS.md`
- `scores4ai (1)/NETLIFY_DEPLOYMENT.md`
- `scores4ai (1)/OPENROUTER_SETUP.md`

Netlify is configured from the repository root with `netlify.toml`; the build base is `scores4ai (1)`. GitHub Actions live deploy automation is configured in `.github/workflows/netlify-deploy.yml` once Netlify repository secrets are added.
